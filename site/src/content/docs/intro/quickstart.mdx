<Steps>

1. Install Go 1.26+

2. Install the Lisette compiler

   <Tabs syncKey="install">
     <TabItem label="curl">
       {/* One command, twice: the single line for a wide viewport, and a continued pair for
           a narrow one, where the single line runs past the block's edge. `custom.css`
           shows one and hides the other at 50rem. */}
       <div class="cmd-wide">
       ```sh
       curl -fsSL https://lisette.run/install.sh | sh
       ```
       </div>

       <div class="cmd-narrow">
       ```sh
       curl -fsSL \
         https://lisette.run/install.sh \
         | sh
       ```
       </div>

       <a class="view-script" href="https://lisette.run/install.sh" target="_blank" rel="noopener noreferrer">View install script</a>
     </TabItem>
     <TabItem label="homebrew">
       ```sh
       brew install lisette
       ```
     </TabItem>
     <TabItem label="mise">
       ```sh
       mise use -g lisette
       ```
     </TabItem>
     <TabItem label="cargo">
       ```sh
       cargo install lisette
       ```
     </TabItem>
   </Tabs>

3. Install the Lisette IDE extension

   <MoreTabs visible={4}>
   <Tabs syncKey="editor">
     <TabItem label="Zed">
       Install the [extension](https://zed.dev/extensions/lisette) from the Zed extension registry
     </TabItem>
     <TabItem label="VSCode">
       Install the [extension](https://marketplace.visualstudio.com/items?itemName=ivov.lisette) from the VSCode marketplace
     </TabItem>
     <TabItem label="Neovim">
       With `lazy.nvim`, add this plugin spec:

       ```lua
       {
         "ivov/lisette",
         event = "VeryLazy",
         config = function(plugin)
           vim.opt.rtp:prepend(plugin.dir .. "/editors/nvim")
           dofile(plugin.dir .. "/editors/nvim/ftdetect/lisette.lua")
           dofile(plugin.dir .. "/editors/nvim/plugin/lisette.lua")
         end,
       }
       ```

       Otherwise, clone the [Lisette repo](https://github.com/ivov/lisette) and add to your `init.lua`:

       ```lua
       vim.opt.rtp:prepend("/path/to/lisette/editors/nvim")
       ```
     </TabItem>
     <TabItem label="JetBrains">
       Install the [extension](https://plugins.jetbrains.com/plugin/31270-lisette) from the JetBrains Marketplace
     </TabItem>
     <TabItem label="Cursor">
       Install the [extension](https://open-vsx.org/extension/ivov/lisette) from the Open VSX Registry
     </TabItem>
     <TabItem label="Helix">
       Add to your `languages.toml` config:

       ```toml
       [language-server.lisette-lsp]
       command = "lis"
       args = ["lsp"]

       [[language]]
       name = "lisette"
       scope = "source.lisette"
       injection-regex = "lis|lisette"
       file-types = ["lis"]
       roots = ["lisette.toml"]
       auto-format = true
       comment-tokens = ["//", "///", "//!"]
       language-servers = ["lisette-lsp"]
       indent = { tab-width = 2, unit = "  " }

       [[grammar]]
       name = "lisette"

       [grammar.source]
       git = "https://github.com/ivov/lisette"
       rev = "121e5eaddac4a0c7818ed4777cfdbdde2df0a786"
       subpath = "editors/tree-sitter-lisette"
       ```
     </TabItem>
     <TabItem label="Emacs">
       Use the community [`lisette-ts-mode`](https://github.com/escherize/lisette-ts-mode) package
     </TabItem>
     <TabItem label="Sublime Text">
       Configure the LSP client to run `lis lsp` for `*.lis` files.
     </TabItem>
   </Tabs>
   </MoreTabs>

</Steps>
