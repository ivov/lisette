Lisette's prelude is the set of declarations available in every file without an import.

- [Numerics](/docs/prelude/numerics/), [Boolean](/docs/prelude/booleans/), [String](/docs/prelude/strings/)
- [Option](/docs/prelude/option/), [Result](/docs/prelude/result/), [Partial](/docs/prelude/partial/), [Array](/docs/prelude/array/), [Slice](/docs/prelude/slice/), [Map](/docs/prelude/map/), [Ref](/docs/prelude/ref/), [Channels](/docs/prelude/channels/), [Ranges](/docs/prelude/ranges/)
- [Functions](/docs/prelude/functions/), [Types](/docs/prelude/types/), [Constraints](/docs/prelude/constraints/)

Use `lis doc prelude` to browse prelude symbols in the terminal.

📚 See [CLI](/docs/cli/)
